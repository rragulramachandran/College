# Assignment 3 Campus Task Planner

Student: 24BCS174

A small PHP and MySQL web application that demonstrates Create, Read, Update, and Delete operations for personal or academic tasks.

## Setup

1. Start Apache and MySQL in XAMPP.
2. Import `schema.sql` using phpMyAdmin.
3. Place this folder inside the XAMPP `htdocs` directory.
4. Open `http://localhost/Assignment_3_TaskPlanner/index.php`.
