# Web and User Interface Design

Laboratory projects and coursework for Web and User Interface Design.

## Projects

| Project | Technologies | Description |
|---------|--------------|-------------|
| [College Course Registration Web Application](College_Course_Registration_Web_Application/) | HTML5, CSS3, JavaScript | Multi-page responsive portal for academic course discovery, faculty listings, departmental programs, and online student course registration with client-side form validation. |

## Topics Covered

- Semantic HTML5 structure and accessible forms
- Responsive CSS layouts, flexbox, CSS grid, and navigation systems
- Client-side DOM manipulation, validation, and user feedback in JavaScript
- Clean UI/UX visual hierarchy and cross-browser styling
