# Network-Adjacent Algorithmic Exercises

C++ implementations of bitwise and string processing challenges relevant to network protocol encoding and framing.

## Problems Solved

| File | Problem | Concept |
|------|---------|---------|
| `338_Counting_Bits.cpp` | LeetCode 338 — Counting Bits | DP + Bitwise manipulation to count set bits for parity generation |
| `3407_Substring_Pattern_Matching.cpp` | LeetCode 3407 — Substring Matching Pattern | String pattern matching for protocol frame headers |
| `49_Group_Anagrams.cpp` | LeetCode 49 — Group Anagrams | Hash maps and frequency counting for payload categorization |
| `String_Processing_CodeChef.cpp` | CodeChef String Challenge | Character parsing, tokenization, and framing simulation |

## Compilation

```bash
g++ -std=c++17 338_Counting_Bits.cpp -o counting_bits
./counting_bits
```
