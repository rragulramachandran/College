# Semester 5 Coursework

Comprehensive repository of laboratory work, programming assignments, and project implementations completed during the fifth semester.

## Course Breakdown

| Folder | Course Name | Primary Languages / Frameworks | Topics & Focus |
|--------|-------------|--------------------------------|----------------|
| [Compiler_Design](Compiler_Design/) | Compiler Design Lab | C, Lex/Flex, YACC/Bison | 19 Lex tokenizers, 14 right-context programs, 28 YACC parsers across 14 groups, quadruple TAC intermediate code generator, code optimization (CSE, constant folding, copy propagation, dead code elimination), and DFA simulator. |
| [Computer_Networks](Computer_Networks/) | Computer Networks Lab | C (POSIX Sockets), C++ (NS-3) | DDCMP/BISYNC/HDLC/PPP framing, CRC error detection, 2D parity & Hamming code correction, Dijkstra & Bellman-Ford routing, TCP & UDP socket servers, concurrent multi-threaded services (ARP, DNS, DHCP, booking, file sharing), sliding window (S&W, GBN, Selective Repeat), and NS-3 simulations. |
| [Operating Systems Laboratory](Operating%20Systems%20Laboratory/) | Operating Systems Lab | C (POSIX System Calls) | Process hierarchies (`fork`), two-way pipes, System V message queues & shared memory, CPU scheduling (FCFS, SJF, Priority, RR), Producer-Consumer semaphores, Banker's deadlock avoidance, memory partition allocation, virtual memory page replacement (FIFO, LRU, OPT), and disk scheduling. |
| [Web-user_interface_design](Web-user_interface_design/) | Web & UI Design | HTML5, CSS3, JavaScript | Multi-page responsive College Course Registration Web Application with dynamic client-side form validation and accessible UI. |
| [FreeOpenSourceSoftware](FreeOpenSourceSoftware/) | Free & Open Source Software | Python, PHP, MariaDB/MySQL | Python text metrics package (`wordkit` in Assignment 2) and 4-table relational Campus Task Planner CRUD web application (Assignment 3). |

Refer to each course directory's dedicated `README.md` for in-depth program notes, architecture diagrams, and compilation guides.
