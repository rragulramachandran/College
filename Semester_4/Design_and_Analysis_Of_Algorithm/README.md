# Design and Analysis of Algorithms Lab

Laboratory programs for the DAA course, implementing fundamental algorithm design techniques and complexity analysis.

All programs are written in **C++** and take user input at runtime.

## Exercise List

| Exercise | Topic | Programs |
|----------|-------|----------|
| EX1 | Brute Force | Bubble Sort, Selection Sort |
| EX2 | Brute Force | Closest Pair of Points, Brute-Force Pattern Matching |
| EX3 | Divide and Conquer | Merge Sort, Quick Sort (Hoare Partition) |
| EX4 | Transform and Conquer | Heap Sort, Insertion Sort |
| EX5 | Space-Time Tradeoff | Kth Smallest Element (Lomuto Partition), Horspool Pattern Matching |
| EX6 | Dynamic Programming | Floyd-Warshall All-Pairs Shortest Path |
| EX7 | Greedy Technique | Huffman Coding (Encoding) |
| EX8 | Backtracking | N-Queens Problem |
| EX9 | Branch and Bound | 0/1 Knapsack Problem |

## Compilation

```bash
cd EX<number>
g++ <filename>.cpp -o output
./output
```
